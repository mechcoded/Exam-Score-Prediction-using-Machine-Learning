This project uses Python and Linear Regression to analyze and predict student grades based on the number of hours studied.
An Excel dataset containing study hours and corresponding grades was processed using Pandas and NumPy, after which a Linear Regression model was trained using scikit-learn to understand the relationship between
study time and academic performance. The model’s performance was evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), and Root Mean Squared Error (RMSE) to measure prediction accuracy.
The trained model was then used to predict grades for new input values, such as estimating the expected grade for a student who studies for seven hours
Finally, Matplotlib was used to visualize the actual data points along with the regression line, clearly demonstrating the positive correlation between study hours and student grades.
